# Repo Quality Checklist

Checklists for keeping SignalFlow safe, clean, and demo ready. The commands
listed can be run locally to verify each item.

## Architecture boundaries

```text
[ ] No app page imports a repository
      grep -rn 'from "@/lib/repositories' app
[ ] No pure engine imports React, Prisma, or the auth client
      grep -rnE 'from "react|@prisma/client|@clerk' lib/ai lib/voice lib/providers lib/feature-flags lib/intelligence lib/scoring lib/outcomes lib/policy
[ ] Repositories filter by organizationId
[ ] Services resolve the request context and pass organization scope down
```

## Security

```text
[ ] Protected routes are guarded server side with guardPage
[ ] Authorization uses the fixed role to permission map
[ ] Detail lookups require both record id and organizationId
[ ] No secret values are committed; .env is gitignored
```

## Provider safety

```text
[ ] No provider SDK is installed
      grep -rnE '"openai"|"@anthropic|"twilio"|elevenlabs' package.json
[ ] No provider persistence field named apiKey, secret, token, credential,
    password, or privateKey
      grep -niE 'apiKey|secret|token|credential|password|privateKey' prisma/schema.prisma
[ ] Required secrets appear only as placeholder names in the registry
[ ] Every live feature flag is disabled by default and blocked in demo mode
[ ] No readiness check marks an external provider live ready
[ ] The provider sandbox always selects an internal mock provider
```

## Demo safety

```text
[ ] No outbound network call
      grep -rnE 'fetch\(|from "axios"' lib app
[ ] No live SMS, email, or voice is sent
[ ] No AI provider API is called
[ ] No real customer data; all data comes from the seed
```

## Docs

```text
[ ] README is portfolio ready and states the demo-safe boundary
[ ] docs/ARCHITECTURE_OVERVIEW.md, DEMO_WALKTHROUGH.md, TECHNICAL_HIGHLIGHTS.md,
    PORTFOLIO_SUMMARY.md, REPO_QUALITY_CHECKLIST.md exist
[ ] Provider docs state no SDKs, no APIs, no network, no secrets
[ ] ROADMAP reflects completed phases and future options
```

## UI demo path

```text
[ ] Landing page links to the Revenue Command Center
[ ] Dashboard shows a provider demo safe status card
[ ] Flagship pages have graceful empty states
[ ] Navigation labels are clear
```

## Validation commands

```text
[ ] npm run build
[ ] npm run typecheck
[ ] npm run lint
[ ] npx prisma validate
[ ] npx prisma migrate status
[ ] npx prisma db seed
```

## Content scans

```text
[ ] Em dash scan is clean (search for the em dash character across ts, tsx, md)
      grep -rn $'\u2014' --include='*.ts' --include='*.tsx' --include='*.md' .
[ ] No AI attribution footers or generated-by comments
      grep -rniE 'generated by claude|built by claude|created with claude'
[ ] No Claude URLs
      grep -rni 'claude.ai'
[ ] No real provider secret env names in code (placeholders allowed)
      grep -rnE 'OPENAI_API_KEY|ANTHROPIC_API_KEY|TWILIO_AUTH_TOKEN|SENDGRID_API_KEY' lib app | grep -v PLACEHOLDER
```
